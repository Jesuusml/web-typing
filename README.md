# TypeFlow ⌨️

**TypeFlow** es una aplicación web pública para aprender y mejorar mecanografía de forma progresiva y accesible. Está pensada para cualquier persona que quiera aumentar su velocidad y precisión al escribir, independientemente de su nivel o de la distribución de su teclado.

Es un proyecto **fullstack** desarrollado de forma individual, centrado tanto en la experiencia de usuario como en una arquitectura clara y escalable.

---

## 🚀 Características

- Ejercicios dinámicos de mecanografía  
- Medición de velocidad (WPM) y precisión  
- Estadísticas y progreso del usuario
- Inicio de sesión con Google  
- Detección de posible distribución de teclado según ubicación  
- Diseño responsive  

---

## 🧠 Objetivo

Ofrecer una herramienta gratuita y sencilla para entrenar mecanografía, aplicando tecnologías modernas de frontend y backend en un proyecto real y usable por cualquier persona.

---

## 🛠️ Tecnologías (Stack Multi-Lenguaje)

### Frontend
- React
- HTML5  
- Sass (SCSS)  

### Backend
- Flask  
- SQL

### Se implementará también con Angular en el frontend y Java en el backend

---

## 🔌 Integraciones externas

- **Google OAuth 2.0**  
  Inicio de sesión seguro mediante cuenta de Google.

- **API de Geolocalización por IP**  
  Detección de ubicación aproximada para sugerir una posible distribución de teclado (QWERTY, AZERTY, QWERTZ, etc.).

- **API de generación de textos (opcional / futura)**  
  Para obtener textos variados según idioma o dificultad.

---

## 🧩 Arquitectura

- Frontend y backend desacoplados  
- API REST con Flask  
- Persistencia de usuarios y estadísticas en base de datos SQL  
- Comunicación mediante JSON
